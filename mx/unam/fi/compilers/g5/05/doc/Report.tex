\section{Introducción} %

%Este apartado debe abordar los siguientes puntos:
Los compiladores son una herramienta importante para la programación informática, estos son un programa informatico que se utiliza para transformar código fuente de alto nivel en código de destino de bajo nivel que el procesador puede ejecutar directamente. \\ 
El compilador se compone de las fases de Análisis Léxico, Análisis Sintáctico, Análisis Semántico, Generación de Código Intermedio, Optimización de Código y Generación de Código Destino. Pero para fines de este reporte únicamente nos enfocaremos en la fase de análisis léxico, cuya función es examinar el código fuente de un programa y dividirlo en unidades básicas llamadas tokens. Estos tokens representan elementos significativos del lenguaje, como palabras reservadas, identificadores, operadores, constantes y signos de puntuación.\\
Sin embargo para que el sistema logre procesar el codigo escrito en un lenguaje de programacion compilado debe de haber un programa que identifique y clasifique cada elemento. De no haberlo este proceso de compilación no podría llevarse a cabo.\\
Por ello surge la necesidad de un analizador léxico que pueda leer una línea de código y automáticamente separarla en lexemas y clasificarla de acuerdo al tipo de token que le corresponde.\\
Al ser la primera fase del proceso de compilación esta tiene un gran peso ya que contruye los cimientos para las fases siguientes. Su importancia radica en la capacidad de simplificar la complejidad sintáctica, optimizando el rendimiento mediante la eliminación de elementos irrelevantes, como espacios y comentarios, y servir como la primera barrera de detección de errores.\\ Comprender su funcionamiento es indispensable dado que es un requisito para el diseño de lenguajes y para nuestra formación como ingenieros en computación. Al comprender el funcionamiento de dicha fase, lograremos adquirir una visión completa de cómo se procesa la información, permitiendo mejorar habilidades para escribir código más robusto, facilitando la depuración técnica y comprendiendo las bases de la seguridad en la validación de datos.\\
El objetivo del proyecto es desarrollar un analizador léxico capaz procesar una entrada de texto que represente código fuente y realizar una identificación automática de los distintos elementos que lo componen, permitiendo separar los elementos significativos del lenguaje y determinar si corresponden a palabras reservadas, identificadores, signos de puntuación, operadores, constantes o cadenas de caracteres. De esta forma el programa generará una representación estructurada de la información encontrada en el código.\\
Finalmente, se busca obtener como resultado un sistema que no solo identifique correctamente cada uno de los tokens presentes en la entrada, sino que también proporcione información clara sobre la clasificación de dichos elementos y la cantidad total de tokens detectados, permitiendo así comprender de manera práctica el funcionamiento del análisis léxico dentro del proceso de compilación.

\section{Marco Teórico}
El proceso de análisis léxico es tan solo una fase de un proceso mayor llamado compilador, esto es un programa informatico que se utiliza para transformar código fuente de alto nivel en código de destino de bajo nivel que el procesador puede ejecutar directamente.\\
La primera fase del compilador es justamente el análisis léxico, en el analizador léxico pasa el código fuente y este lee los caracteres de la entrada y los agrupa en unidades significativas llamadas token, junto con un símbolo terminal que se utiliza para las decisiones de análisis sintáctico. Un token representa una categoría léxica dentro de un lenguaje de programación, como palabras reservadas, identificadores, operadores, constantes numéricas o signos de puntuación. Una secuencia de entreda que conforma un token se le llama lexema, por tanto, el analizador léxico aísla al analizador sintáctico de la representación de los tokens mediante lexemas.\\
Para realizar este reconocimiento, los analizadores léxicos utilizan mecanismos de identificación de patrones que permiten clasificar cada fragmento del texto de entrada. Estos patrones suelen describirse mediante expresiones regulares, las cuales permiten definir de forma formal cómo se pueden formar ciertos elementos del lenguaje.\\
La función principal del analizador léxico es recorrer el programa y agrupar los caracteres en lexemas para después ser clasificados en tokens. Estos luego son enviados a la siguiente fase del compilador que es el analizador sintáctico para verificar que la secuencia de tokens cumpla con las reglas gramaticales del lenguaje.\\
El analizador léxico tambien se encarga de eliminar los espacios en blanco (espacios, tabulaciones y saltos de línea) o comentarios dentro de las expresiones, para que así el analizador sintáctico no tenga que tomarlos en cuenta evitando tener que modificar la gramatica.
Podemos observar que el analizador léxico funciona como un filtro que organiza la información del programa antes de un mayor análisis.~\cite{aho2006compilers}
